VALIDACIONES QUE DEBEN EJECUTARSE EN WINDOWS
=============================================
El build Angular completo no se ejecutó en este contenedor porque Angular CLI
22.1.8 exige Node.js >=22.22.3 o >=24.15.0 y el contenedor tiene v22.16.0.

Vitest tampoco pudo iniciar con los node_modules heredados desde Windows porque
sus bindings nativos no corresponden a Linux. El ZIP final excluye node_modules;
por lo tanto, npm ci instalará los binarios correctos en el equipo de pruebas.

Ejecutar con Node.js 24.22.2:
  npm ci
  npm --prefix functions ci
  npm run lint
  npm run build
  npm run lint:functions
  npm run build:functions
  npm run test:unit
  npm run test:functions
